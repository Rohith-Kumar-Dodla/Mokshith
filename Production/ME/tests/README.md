# Playwright Automation Framework (Scaffold)

This folder contains the scaffold and architecture for an enterprise-grade Playwright automation framework tailored for the MERN B2B platform.

Structure purpose:
- docs/: Test strategy, plans, inventory and templates
- config/: Environment and constants configuration
- fixtures/: Test fixtures definitions (no implementation)
- pages/, components/: Page object folders and UI component maps
- helpers/, utils/: Helper modules and utilities (no implementation)
- mocks/: Mock assets for API/payment/upload (no implementation)
- test-data/: Organized test data per business module
- api/: API test folders aligned with backend modules
- e2e/, smoke/, sanity/, regression/: Test suites organization (suites only — no test files)
- reports/, screenshots/, videos/, traces/, results/: Artifacts and CI outputs

NOTE: This repository contains only structure and documentation. No test code, Playwright scripts, or implementation were added.
