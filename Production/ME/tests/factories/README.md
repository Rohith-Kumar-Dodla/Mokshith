Factories — Test data factories
===============================

Purpose
-------
Define canonical factory contracts for creating test data objects (design only). Factories will drive deterministic and reusable test data across suites.

Planned factory files
- user.factory.md
- vendor.factory.md
- product.factory.md
- order.factory.md
- category.factory.md
- inventory.factory.md

Guidelines
- Factories must document required fields, optional fields and cleanup semantics.
- Support deterministic seeds for repeatable tests.
