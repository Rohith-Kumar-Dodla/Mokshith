Flows — Business workflow definitions
====================================

Purpose
-------
Describe and centralize canonical business flows. Flows are documented sequences that tests will reference to build E2E scenarios (design only — no test code).

Planned flow files
- authentication.flow.md
- checkout.flow.md
- order-lifecycle.flow.md
- payment.flow.md
- inventory.reservation.flow.md
- delivery.assignment.flow.md
- vendor.onboarding.flow.md
- admin.approval.flow.md

Each flow file will contain:
- Actors and roles
- Pre-conditions and post-conditions
- Step-by-step business steps
- API/webhook touchpoints
- Failure modes and recovery actions
