NAMING CONVENTIONS
==================

Purpose
-------
Define naming rules for files, page objects, selectors, factories, validators, tests and folders.

Key rules
- Page objects: PascalCase (e.g., LoginPage)
- Selector files: module.selectors.md
- Factories: module.factory.md
- Validators: module.validator.md
- Tests: suite.module.feature.spec.ts (implementation phase)
- Keep names short, descriptive and consistent.
