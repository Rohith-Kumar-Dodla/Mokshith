# QA Dataset Builder — Future Improvements

Potential roadmap items (design-only)

- Plugin architecture: allow custom generators for domain-specific data.  
- Multiple datasets: support parallel named datasets (smoke, integration, perf).  
- Randomized datasets: seeded stochastic variations (for fuzz/perf).  
- Performance mode: generate minimal but high-volume datasets for load testing.  
- Cloud execution: run builder as ephemeral job in CI/CD or cloud workspace with scale-out.  
- UI dashboard: monitor runs, replays, and artifact browsing.
