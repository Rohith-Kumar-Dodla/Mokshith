# QA Dataset Generation — Layers

Layer 1 — Reference Data (deterministic fixtures)
- Countries, currencies, tax rules, categories, warehouses, settings, feature flags.
- Immutable inputs for downstream layers.

Layer 2 — Users & Accounts
- SuperAdmin, Admins, Vendors, Delivery Partners (core fixtures); Customers via registration flows.
- Dependencies: companies, vendor companies.

Layer 3 — Business Entities
- Products, Promotions, Company/Vendor profiles, Warehouses.
- Created by vendors/admins (APIs) or canonical fixtures for a baseline catalog.

Layer 4 — Transactional Data (application-driven)
- Orders, Payments, Shipments, Invoices, Refunds, Notifications, Audit logs.
- MUST be generated by application checkout/payment/fulfillment flows to exercise business logic and workers.

Layer 5 — Runtime Data
- Queues, temporary sessions, analytics events — created by flows and worker processing.

Design notes
- Each layer depends on the previous; orchestration enforces order and validation between layers.
- Generation jobs must record manifest version and run metadata.
